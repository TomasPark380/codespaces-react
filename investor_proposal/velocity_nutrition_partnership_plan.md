# Velocity Nutrition — 영양 공급사 제휴·소분 실행안

> 목표: 고객이 "이건 다르다"고 느끼는 맞춤형 영양제를, 규제 안에서, 인허가·재고 부담 없이 12주 안에 출시한다.
> 모든 원료·기능성 문구는 식약처 인정 내용 그대로만 쓴다. 판매 전 원료별 인정서와 법률 검토로 최종 확정한다.

---

## 1. 고객이 "획기적"이라고 느끼는 지점

기능성 원료 자체는 어디서나 살 수 있다. 차별점은 **"내 몸 숫자로 고르고, 내 몸 숫자로 확인한다"**는 경험이다.

| 장치 | 고객이 느끼는 것 | 구현 |
|---|---|---|
| **측정 기반 조합** | "설문 말고 내 피부·HRV 데이터로 골랐다" | PCP v3 신호 → 목표 프로그램·원료 자동 추천 |
| **4주 Before/After 카드** | "먹고 나서 내 수치가 어떻게 변했는지 보인다" | 4주 재측정 결과를 공유 카드로 생성 (측정 변화만 표시, 인과 단정 금지) |
| **시간대 파우치** | "아침·저녁·운동 후, 먹는 때까지 정해 준다" | AM / PM / 운동 후(Move) 3종 파우치 |
| **궁합 설계** | "같이 먹어야 좋은 건 한 봉지에, 따로 먹어야 할 건 따로" | 콜라겐+비타민C 동봉, 칼슘·철 분리 등 규칙 엔진 |
| **안전 엔진** | "중복·과다·약물 충돌을 알아서 막아 준다" | 상한섭취량 합산 검사, 복용약 필터, 금지 병용 차단 |
| **매달 조합 업데이트** | "고정 제품이 아니라 나에 맞춰 바뀐다" | 재측정 결과로 다음 달 원료·용량 조정 |
| **만족 보장** | "안 맞으면 다음 달 조합을 무료로 바꿔 준다" | 첫 달 조합 재설계 무료 (효능 보장이 아닌 서비스 보장) |

## 2. 목표 프로그램 5종과 원료 설계

고객이 원하는 말(살찌는 것 방지, 노화방지…)을 **식약처가 인정한 기능성 언어**로 바꿔 설계한다.
"노화방지", "살 빠짐 보장", "주름 제거" 같은 표현은 광고에 쓸 수 없다.

| 프로그램 (고객용 이름) | 고객의 바람 | 인정 기능성으로 바꾼 목표 | 원료 후보 | 구분 |
|---|---|---|---|---|
| **Slim Velocity** | 살찌는 것 방지 | 체지방 감소에 도움 | 녹차추출물(카테킨), 공액리놀레산(CLA), 가르시니아캄보지아 껍질추출물 중 **1종만** | 고시형 |
| **Skin Velocity** | 주름·피부 탄력 | 피부 보습 · 자외선에 의한 피부 손상 보호 · (인정받은 원료에 한해) 피부 주름 개선 | 저분자 콜라겐펩타이드, 히알루론산 | 개별인정형 |
| **Collagen+** | 콜라겐 흡수 | 위와 동일 + 결합조직 형성과 기능 유지 | 저분자 콜라겐펩타이드 + **비타민C 동봉** | 개별인정 + 영양성분 |
| **Muscle Velocity** | 근육 강화 | 근력 운동 시 운동수행능력 향상 · 신체조직 구성 · 뼈 형성 | 크레아틴, 단백질, 비타민D, (인정 조건 충족 시) HMB | 고시형 · 개별인정형 |
| **Antiox Velocity** | 노화방지 | 유해산소로부터 세포 보호 (항산화) | 비타민C, 비타민E, 셀레늄, 코엔자임Q10 | 영양성분 · 고시형 |

공통 기본층(Base): 종합비타민·미네랄, 오메가3(혈행 개선·혈중 중성지질 개선), 프로바이오틱스(장 건강) 중 측정·문진 결과로 선택.

### 반드시 넣을 안전 규칙 (추천 엔진에 코드로 구현)
1. **체지방 원료는 한 조합에 1종만.** 식약처는 가르시니아캄보지아 추출물을 녹차추출물 등 다른 체지방 감소 원료와 함께 섭취하지 않도록 주의사항을 두고 있다.
2. **성분 합산 상한 검사.** 종합비타민 + 단일 원료에서 같은 성분(비타민 A·D·E, 아연, 셀레늄 등)이 겹치면 합산량이 상한섭취량 이하인지 확인한다.
3. **복용약 필터.** 항응고제 복용 시 오메가3·비타민E는 관리사 확인 필수, 간·신장 질환자는 가르시니아 제외 등.
4. **대상 제한.** 임신·수유부, 청소년, 원료별 인정 연령 조건(예: 크레아틴 성인, HMB 인정 조건)을 확인한다.
5. **관리사 최종 승인.** 엔진 결과는 추천안이며 맞춤형건강기능식품관리사가 확정한다.

## 3. 제휴 구조 — 누가 무엇을 하는가

```
[원료·완제품 공급사 (건기식 ODM/브랜드)]
        │  완제품 벌크(정제·캡슐) 공급 · 시험성적서 · 기능성 인정서
        ▼
[맞춤형 건강기능식품 판매업체 (약국 체인·전문 소분센터)]
        │  관리사 상담 · 소분·조합 · 표시 · 출고  (수탁 소분도 가능)
        ▼
[고객]  ◀──── 측정·추천·4주 재측정·리포트 ──── [PHYDRION]
```

| 주체 | 역할 | Phydrion과의 계약 |
|---|---|---|
| **원료·완제품 공급사** (2곳 이상) | 프로그램별 완제품 SKU 공급 | 공급 단가·MOQ·리드타임·우선공급 협약 (판매업체와 3자 계약 또는 판매업체 직계약) |
| **맞춤형 판매업체** (1곳 → 확대) | 판매업 신고 보유, 관리사 상주, 소분·출고, 품질 책임 | 추천 API 연동 + 판매액 20% 수수료 + 데이터 처리 위탁 |
| **물류** | 박스 포장·배송 | 판매업체 또는 Phydrion 계약 |
| **PHYDRION** | 측정·문진·추천 엔진, 고객 앱, 마케팅, 재측정 리포트 | 브랜드(Velocity Nutrition) 라이선스, 고객 접점 소유 |

### 공급사를 고르는 기준 (체크리스트)
- [ ] GMP 인증 시설, 원료별 **기능성 인정서·시험성적서(COA)** 제출
- [ ] **소분기 호환 제형**: 정제·경질캡슐 위주, 크기·코팅 규격 통일 (분말·액상은 1단계 제외)
- [ ] **벌크 공급**: 병·대용량 포장, 입고 시 **소비기한 잔여 12개월 이상**
- [ ] 개별인정 원료는 **인정받은 원료사의 원료로 만든 제품**인지 확인
- [ ] 소량 MOQ(SKU당 수천 정 단위) 허용, 리드타임 4주 이내
- [ ] 회수(리콜) 발생 시 책임·비용 분담 조항 수용

## 4. 소분 운영 절차 (SOP)

| 순서 | 작업 | 기준 |
|---|---|---|
| 1 | 앱 주문 → 추천안 생성 | 안전 규칙 1~4 자동 통과분만 넘김 |
| 2 | 관리사 상담·승인 | 첫 구매 상담 기록, 조합 확정 (비대면 허용 범위는 법률 검토 후) |
| 3 | 소분 지시서 발행 | 고객별 바코드, AM/PM/Move 파우치 구성, 28일분 |
| 4 | 자동 분배·파우치 포장 | 위생 구역, 정제·캡슐 원형 그대로 소분(캡슐 개봉·분쇄 금지) |
| 5 | 파우치 인쇄 | 이름·섭취 시간·제품명·소분일자 |
| 6 | 비전·중량 검수 | 정제 수·종류 자동 판독, 불일치 시 재작업 |
| 7 | 박스 표시·포장 | 법정 표시사항 + 보정 카드 + 4주 측정 QR |
| 8 | 출고·기록 보관 | 주문 후 D+2 출고, 원료 로트–고객 추적 기록 |

**법정 표시사항**: "맞춤형 건강기능식품" 문구, 소비자 이름, 제품명, 기능성 원료 또는 영양성분, 일일섭취량, 섭취 방법, 보관 방법, 소비기한(원 제품 기한 이내), 소분·조합 일자, 판매업소 명칭·소재지(위탁 시 수탁자 포함).

| 항목 | 금액 (원) |
|---|---|
| 완제품 원료 원가 (5종 28일분) | 9,000 ~ 13,000 |
| 소분·파우치·인쇄 | 2,000 ~ 3,000 |
| 박스·보정 카드 | 1,000 |
| 배송 | 3,000 |
| 관리사 상담·운영 | 3,000 ~ 5,000 |

| 판매업체 몫 | 약 7,000 ~ 13,000 |

업계 통상 수준으로 잡은 추정치이며, 공급사·판매업체 견적으로 교체한다.

## 6. 12주 출시 계획

| 주차 | 할 일 | 산출물 |
|---|---|---|
| 1–2 | 판매업체 1곳, 공급사 2곳 선정 · NDA | 제휴 의향서(LOI) |
| 3–4 | SKU 20~25종 확정 · 인정서/COA 수령 · 표시·광고 문구 법률 검토 | SKU 마스터, 문구 가이드 |
| 5–6 | 추천 엔진 + 안전 규칙 구현, 판매업체 주문 연동 | 추천 API, 소분 지시서 양식 |
| 7–8 | 내부 테스트 50명 (임직원·지인 제외 기준 마련) | 소분 SOP 검증 |
| 9–12 | 베타 300명 · 4주 체험 박스 | KPI 리포트 |

**베타 KPI (투자자에게 보여줄 숫자)**
- 체험 → 정기 구독 전환율 **30% 이상**
- 4주 재측정률 **60% 이상**
- 2개월 차 구독 유지율 **70% 이상**
- 이상사례 0건, 고객 만족도(NPS) 40 이상

## 7. 쓰면 안 되는 표현 / 써도 되는 표현

| 금지 (광고·앱·패키지) | 대체 표현 |
|---|---|
| 노화방지, 젊어지는 영양제 | 항산화 · 유해산소로부터 세포 보호에 도움 |
| 살 빠지는, 다이어트 보장 | 체지방 감소에 도움을 줄 수 있음 |
| 주름 제거, 피부 재생 | 피부 보습에 도움 · (인정 원료) 피부 주름 개선에 도움 |
| 콜라겐 흡수율 ○배 | 저분자 콜라겐펩타이드 + 결합조직 형성에 필요한 비타민C |
| 측정 결과로 질병 예측·진단 | 생활 관리 참고 지표 · 변화 추이 |

## 확인이 필요한 사항
- 맞춤형 건강기능식품 비대면(온라인) 상담·재구매 허용 범위
- 원료별 인정 기능성 문구·인정 조건(연령 등) — 특히 HMB, 피부 주름 관련 콜라겐 원료
- 개인 건강정보(민감정보)를 판매업체에 넘길 때의 동의 절차와 위탁 계약
